# EVERNIGHT NETWORK — серверный аудит

Этот репозиторий предназначен для проверки Minecraft Java Network: Paper/Purpur/Spigot/Bukkit, Velocity и BungeeCord.

**Важное:** Репозиторий необходимо сделать **Private** до размещения реальной серверной сборки. Никогда не коммитьте пароли, приватные ключи, конфигурацию БД, токены и полный сервер в публичный Git.

## Что делает аудит

- Перечисляет JAR, определяет название и версию плагина из `plugin.yml`, `paper-plugin.yml`, `velocity-plugin.json` и `bungee.yml`.
- Проверяет отсутствующие обязательные зависимости, дубли плагинов и некорректные метаданные.
- Определяет версии Java по class-файлам (проверка на Java 21).
- Проверяет синтаксис стандартных YAML/TOML-конфигураций и ищет распространённые признаки ошибок в логах без публикации строк логов.
- Формирует безопасный JSON и Markdown отчёты. Секретные значения и содержимое логов в отчёт не включаются.

**Ограничение:** Статический аудит — это не гарантия работоспособности всех плагинов. После исправлений требуется тестовый запуск Paper/Velocity и проверка команд, событий, БД и режимов игры.

## Как запустить аудит через GitHub Actions

1. В **Settings → General → Danger Zone → Change repository visibility** установите **Private**.
2. В **Releases** создайте релиз с тегом `audit-input`; загрузите один из серверных архивов `Evernight Network.zip` или `Evernight Network.rar` в **Assets**. Для release assets поддерживаются файлы больше 100 МБ; обычные коммиты для такого архива не подходят. По возможности исключите из архива действующие пароли, токены, приватные ключи, миры и резервные копии.
3. В **Actions → EVERNIGHT Network Audit → Run workflow** запустите проверку.
4. Отчёты доступны в артефакте `evernight-audit-report` и в Summary запуска.

### Безопасность

- Workflow проверяет приватность репозитория **до** загрузки сборки. На публичном репозитории аудит архивов не запускается.
- Сборка не публикуется в исходниках репозитория и не выгружается обратно как GitHub Actions artifact.
- Отчёт содержит только названия/версии плагинов, типы ошибок и пути, но не значения настроек.
- GitHub Actions лог и артефакты частного репозитория доступны участникам с соответствующими разрешениями.

## Локальный режим без CI

```bash
python -m pip install -r tools/requirements.txt
python tools/audit.py --root /path/to/extracted/server --out /path/to/report
```

Запуск локально необязателен, если используете GitHub Actions.
